# Аудит дизайна и UI/UX — Task Tracker AVANT

Дата: 13.11.2026. Ветка/рабочая копия: локальная `tasktracker` (Laravel 13 + Livewire 3/Volt + Tailwind 3, шаблон Breeze).
Код не менялся. Скриншоты — `docs/design-audit/` (113 файлов).

**Как снималось.** `php artisan serve` на копии локальной SQLite (25 пользователей, 18 задач, 9 встреч, оплаты), внешние сервисы отключены через env (почта → log, Telegram/OpenAI/Fireflies пустые). Вход под админом и под рядовым сотрудником (пароль выставлен только в копии БД). Playwright + системный Chrome, ширины 1440 / 1024 / 768 / 390. Тёмной темы в приложении нет (`dark:` встречается в 2 файлах из ~100, `darkMode` не настроен) — снималась только светлая.

> ⚠️ В скриншотах реальные имена, email сотрудников и суммы оплат. Папку `docs/design-audit/` **не коммитить** (или добавить в `.gitignore`).

## 1. Краткий вывод — почему выглядит «навайбкоженно»

1. **Это стоковый Breeze/Tailwind без бренда.** Шрифт Figtree из шаблона, основной цвет — дефолтный `indigo-600 #4f46e5`, серые — дефолтный `gray`. Логотип AVANT (тёмно-синий + золото) с интерфейсом никак не связан. `tailwind.config.js` расширяет только `fontFamily` — ни одного собственного токена.
2. **Нет иерархии действий.** В шапке задачи 4 цветные кнопки подряд (3 красные + 1 синяя), «Редактировать» — серая ссылка; главное действие не читается (`task-show-1440.png`). Красный = «опасно», а им покрашены обычные статусы «Отклонена/Отменена».
3. **Три разных языка кнопок одновременно.** Breeze-кнопки КАПСОМ с `tracking-widest` (`СОЗДАТЬ ЗАДАЧУ`, `СОХРАНИТЬ`, `ДОБАВИТЬ`), рядом обычные `action-button` sm в регистре предложения, рядом голые нестилизованные `<input type=file>` в системном виде («Выбрать файлы | Файл не выбран»).
4. **Плитки ради плиток.** Всё в белых карточках `rounded-xl shadow-sm border` на сером фоне, включая фильтр периода, поиск и одну строку KPI; «Сведения», «Наблюдатели», «Вложения» — три карточки там, где нужна одна панель. Дашборд — сетка одинаковых по весу карточек.
5. **Заглушки и шаблонные тексты в проде.** В админке у всех 8 разделов одно описание «Фаза 1: управление подразделениями…» (`admin-1440.png`), «Данных пока нет.» набрано 30px жирным как главная цифра (`dashboard-1440.png`), 404 — голая «404 | Not Found» на английском, ошибки валидации «Поле **title** обязательно».
6. **Адаптив сломан на планшете.** На 768 и 1024 px десктопная шапка не помещается — горизонтальный скролл на **всех** страницах после входа (ширина документа 1103–1111 px). На 390 карточка встречи тоже шире экрана (439 px).
7. **Доступность ниже AA.** 80 полей без подписи (axe `label`/`select-name`), 79 нарушений контраста (`text-gray-400` на белом = 2.53:1 используется 61 раз), 47 вложенных интерактивных элементов в «Оплатах».

## 5. Предлагаемая дизайн-система (в рамках Tailwind 3)

Всё задаётся в `tailwind.config.js` (`theme.extend`) и CSS-переменных в `resources/css/app.css`, без новых зависимостей.

### Палитра
Опираемся на логотип: тёмно-синий + золото. Точные значения сверить с брендбуком AVANT.

| Токен | Значение (предложение) | Применение |
|---|---|---|
| `brand-900` | `#14213D` | шапка/навигация (тёмная), заголовки |
| `primary-600` / `-700` | `#1F3A8A` / `#172E6E` | одна главная кнопка на экране, ссылки, активный пункт меню |
| `primary-50` | `#EEF2FA` | фон активного пункта, выделение строки |
| `accent-500` | `#C9A227` (золото) | **только** «срочно» и редкие акценты бренда (вместо 🔥) |
| `neutral-0…900` | одна шкала (`gray` → `slate` или своя тёплая), без zinc | текст, фоны, границы |
| `success-600/50` | `#15803D` / `#F0FDF4` | «Выполнена», оплачено |
| `warning-600/50` | `#B45309` / `#FFFBEB` | «На проверке», «скоро срок» |
| `danger-600/50` | `#B91C1C` / `#FEF2F2` | просрочено, удаление |
| `info-600/50` | `#1D4ED8` / `#EFF6FF` | «В работе» |

Статусы сводятся к 4 тонам: нейтральный (Новая, Отложена, Ожидает данных), info (В работе, На доработке), warning (На проверке), success (Выполнена), приглушённый серый с зачёркиванием/иконкой для Отклонена/Отменена — без красного.

Текст минимум `neutral-600` на белом (≥ 4.5:1); `neutral-400` — только для иконок и неактивных элементов.

### Типографика
Шрифт: оставить один нейтральный гротеск с кириллицей и цифрами `tabular-nums` — **Inter** или **Manrope** (самостоятельно хостить через Vite вместо bunny.net). Шкала:

| Токен | Размер / высота строки | Вес | Где |
|---|---|---|---|
| `caption` | 12 / 16 | 500 | подписи, метаданные, `th` |
| `body-sm` | 13 / 20 | 400 | таблицы, плотные списки |
| `body` | 14 / 20 | 400 | основной текст интерфейса |
| `title-sm` | 16 / 24 | 600 | заголовки карточек и секций |
| `title` | 20 / 28 | 600 | заголовок страницы |
| `display` | 24 / 32 | 600 | цифры KPI |

Без КАПСА в кнопках. `th` — `caption` в обычном регистре (или КАПС с `tracking-wide`, но тогда только там).

### Отступы
4-пиксельная сетка, 8 шагов: **4 · 8 · 12 · 16 · 24 · 32 · 48 · 64**. Правило: внутри компонента 8–12, между полями 16, между секциями 24–32, поля страницы 24 (desktop) / 16 (mobile). Убрать 0.5/1.5/2.5/3.5/7/9.

### Радиусы и тени
- Радиус: `sm = 6px` (поля, кнопки, бейджи), `md = 10px` (карточки, модалки, поповеры), `full` (аватары, счётчики).
- Тени: карточки **без тени**, только `1px border neutral-200`; `shadow-overlay` (`0 8px 24px rgb(15 23 42 / .12)`) — только для всплывающих слоёв.

### Кнопки (один компонент `x-button`, заменяет 4 текущих)
- Варианты: `primary` (залитая, **не больше одной на экран/блок**), `secondary` (белая с границей), `ghost` (без фона — для вторичных действий в строках), `danger` (только подтверждение в модалке; в обычном интерфейсе — `ghost` красным текстом).
- Размеры: `sm` 32px, `md` 36px; иконка 16px, gap 8.
- Регистр предложения, вес 500, без `tracking-widest`.
- Статусы задачи: одна primary «следующий шаг» (например, «Взять в работу»), остальное — меню «Изменить статус ▾». «Удалить» — в меню «⋯».

### Поля
Один `x-input`/`x-select`/`x-textarea`/`x-file-input`: высота 36px, радиус 6, граница `neutral-300`, фокус — ринг `primary-600` 2px. Подпись всегда связана через `for`/`id` (закрывает 80 нарушений axe). Ошибка — текст `danger-600` 12px + красная граница + `aria-describedby`. Файл — собственная кнопка «Прикрепить файл» с иконкой + drop-зона. Множественный выбор людей — существующий `x-combobox` вместо `<select multiple>`.

### Таблицы
Строка 44px (плотная 36px), разделители `neutral-100`, без зебры, hover `neutral-50`. Действия в строке — `ghost` иконки, видимые по hover/focus и всегда на тач-устройствах; опасные — в меню «⋯». Кликабельная строка — через ссылку в первой ячейке (растянутый `::after`), а не `tr role=button` с кнопками внутри. Числа и даты — `tabular-nums`, по правому краю.

### Карточки
Карточка — только для независимого блока. Не класть фильтры и поиск в отдельную карточку: тулбар лежит прямо на фоне страницы. Сайдбар задачи — одна панель с разделителями. Никаких карточек внутри карточек.

### Иконки и эмодзи
Один набор — Heroicons outline 1.5px (уже используется в навигации), размеры 16/20. Эмодзи 🔥 🔒 ▶ ✕ 📄 ✅ → иконки `fire`, `lock-closed`, `play`, `x-mark`, `document`, `check`.
